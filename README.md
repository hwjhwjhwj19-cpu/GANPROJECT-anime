# GAN Anime Face Generation

# Overview
This is a beginner-level project where I implemented a basic GAN (DCGAN) to generate anime-style face images.
The goal of this project was to understand how generative models work in practice, including model architecture, training dynamics, and common issues such as instability.

## What I Did
- Built a Generator and Discriminator using convolutional layers  
- Trained the model on an anime face dataset  
- Implemented the adversarial training process  
- Observed training behavior and adjusted hyperparameters  

## Notes
This project is mainly for learning purposes. Through this implementation, I gained hands-on experience with GANs and developed an interest in more advanced generative models such as diffusion models.
